# OptBench

**OptBench** — реляционная база данных для бенчмаркинга алгоритмов оптимизации и моделей машинного обучения. Проект структурирует метаданные эксперментов, конфигурации запусков и логи итераций для удобного анализа сходимости.

## Структура репозитория
* `./schemas` — концептуальная, логическая и физическая схемы базы данных.
* `./data` — DDL/DML скрипты и сгенерированные датасеты (CSV).
* `./base_part` — базовая структура БД и набор обязательных SELECT-запросов.
* `./advanced_part` — индексы, представления (views), триггеры и хранимые процедуры.
* `./tests` — тесты логики БД.
